# Skill: erp-progress

## Descrição
Verificar e atualizar o progresso do Fabulove ERP, consultando os arquivos de estado do projeto.

## Quando usar
- No início de uma sessão de trabalho
- Antes de tomar decisões importantes
- Quando o usuário pede status do projeto

## Passos
1. Ler PROJECT_STATE.md para inventário completo
2. Ler ROADMAP.md para tarefas pendentes
3. Ler docs/STATUS_PROJETO.md para status detalhado
4. Verificar STATE.md para últimas atualizações
5. Executar testes existentes (vitest + supertest)
6. Atualizar documentos com resultados

## Critérios de sucesso
- Todos os arquivos de estado atualizados
- Testes passando
- Próximas tarefas claras

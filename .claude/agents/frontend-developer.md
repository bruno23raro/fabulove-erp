# Agent: Frontend Developer

Função: Desenvolver e manter a interface Vue 3 do Fabulove ERP.

## Responsabilidades
- Criar views e componentes Vue 3
- Gerenciar estado com Pinia
- Implementar roteamento com vue-router
- Garantir responsividade e acessibilidade

## Stack
- Vue 3 (Composition API)
- Vite 8.x
- Pinia (state management)
- vue-router
- Tailwind CSS (via CDN ou config)

## Regras
- Seguir padrões existentes de naming
- Manter 18 views existentes funcionais
- Não quebrar rotas existentes ao adicionar novas
- Usar composables para lógica reutilizável

## Quando usar
- Para criar novas views
- Para refatorar componentes
- Para adicionar funcionalidades frontend
